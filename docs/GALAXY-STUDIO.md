# OrbitNest Galaxy Studio

Galaxy Studio is a separate extension page beside the main WebGL Universe and Galaxy Lab. It uses a Canvas 2D procedural sphere renderer (3D-style lighting), not a WebGL substitute. The original WebGL page remains unchanged.

## Controls

- Drag to pan; scroll to zoom toward your pointer; F or Fit all to recenter.
- Change formation, atmosphere, and lens independently. Presets remain local.
- Select a planet and activate its existing tab; no tab is closed automatically.
- Metadata remains local. No page bodies, passwords, or chat contents are accessed.

## Build

Run `npm run check` and open the unpacked extension from `dist`.
